## O case study mudou de sítio a 4 de setembro de 2026

Havia aqui um `case-study-linkedin.md`, em markdown. Foi apagado. A versão boa
está em `docs/case-study/`, com PDF gerado e verificado:

| Ficheiro | O que é |
|---|---|
| `case-study.pdf` | 15 páginas. A versão longa, para os Destaques do perfil |
| `carrossel.pdf` | 10 slides com a espinha no custo. É o que vai ao feed |
| `carrossel-en.pdf` | O mesmo, em inglês |
| `carrossel-base.pdf` | 10 slides com a espinha na base de conhecimento |
| `post-linkedin.md` | O texto, a ordem de publicação e as regras do feed |

O ficheiro antigo ficou para trás em 3 de setembro e passou a contradizer os
outros nos números. Três sítios a contar a mesma coisa com valores diferentes
não é redundância, é uma armadilha para quem lê o errado. Continua no
histórico do git se alguém precisar dele.
